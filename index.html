ArkTS / ArkUI ArkUI-X Node.js 后端 com.heima.cloudmusic 6.0.0

黑马云音乐

HarmonyOS ArkTS 音乐应用，经 ArkUI-X 运行于安卓设备；配套零依赖 Node.js 后端 API。个人学习项目，与官方音乐平台无关。

查看源码 配套运行器

功能特性

首页推荐

轮播 Banner、每日推荐、推荐歌单；远程数据优先，拉取失败回退内置本地样本。

音乐与动态

歌曲标题、歌手、封面、时长；动态列表内嵌歌曲信息，字段多别名兼容解析。

播放页

封面、进度、上一首 / 播放暂停 / 下一首；当前为计时模拟，AVPlayer 真播放待接入。

服务器设置

地址运行时可配并持久化到 Preferences；首页顶部标记远程数据 / 本地演示状态。

统一数据层

入口页生命周期预加载写入 AppStorage，子视图 @StorageLink 订阅，规避 ArkUI-X 生命周期不回调问题。

零依赖后端

Node 原生 http 提供五个业务接口与静态资源；改 JSON 数据无需重启进程。
